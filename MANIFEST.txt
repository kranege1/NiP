🚀 QUICKSTART (3 STEPS):

1. INSTALL
   $ pip install -r requirements.txt

2. CONFIGURE
   $ $env:GROK_API_KEY = "your-grok-api-key"  # PowerShell
   $ export GROK_API_KEY=...                   # Bash/Zsh
   $ set GROK_API_KEY=...                      # CMD

3. RUN
   $ python server.py
   $ # or: node server.js

4. TEST (Optional)
   $ python test_grok.py "your-grok-api-key"

│   -d '{"prompt": "Wer war Einstein?"}'                                │
│                                                                         │

│                                                                         │
